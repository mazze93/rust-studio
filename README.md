# Rust Studio

Open **rust-primer.html** in your browser. It is a self-contained offline guide with 15 chapters, six interactive ownership experiments, searchable chapter navigation, copy buttons, local exercise progress, and 26 source links.

- `starter/`: ready-to-run CLI/library project; start with its README.md.
- `examples/`: fourteen standalone Rust examples, including three intentional compiler failures. `manifest.json` records expected outcomes.
- `installation-report.md`: installed versions, verification, limits and maintenance.
- `validation.json` and `validation.log`: compiler/build checks with command exit status; later retries are retained separately.
- `sources.json`: dated primary-source reading list.

The HTML is current to the verified Rust 1.99.1 release on **2026-10-31**, not automatically updated. External source links need internet access. No HTML interaction sends code or progress to a service.
